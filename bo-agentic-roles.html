Business Operations · Agent Catalog · Strategic Cyber Services

BOAgenticRoles

Agent roles are bounded digital workers. They gather, correlate, draft, recommend and route work. Humans retain authority for risk acceptance, destructive or disruptive actions, legal assertions, external attestations and material security changes.

CLIENT / MISSION → INTAKE → ASSET GRAPH → EXPOSURE → THREAT CONTEXT → RISK → REMEDIATION → VALIDATION → EVIDENCE → EXECUTIVE DECISION
SCS-01 · CYBER CONCIERGE

Engagement Intake Agent

Front door for the subdivision. Converts business questions into scoped cyber work.

Inputs: mission, systems, stakeholders, contracts, constraints, requested outcomes.
Outputs: engagement charter, data request, RACI, initial backlog, escalation flags.

SCS-02 · CARTOGRAPHER

Asset Intelligence Agent

Builds the governed asset and dependency graph.

Inputs: CMDB, cloud, endpoint, network, DNS, IAM, app, OT/IoT and supplier inventories.
Outputs: normalized assets, ownership gaps, criticality tags, unknown/shadow assets, dependency map.

SCS-03 · LANTERN

Exposure Correlation Agent

Deduplicates findings and links them to assets and controls.

Inputs: vulnerability scanners, AppSec, config scans, pentests, audits.
Outputs: canonical findings, duplicates removed, affected asset sets, evidence confidence.

SCS-04 · COYOTE

Threat Context Agent

Enriches exposure with exploitation and adversary context.

Inputs: CISA KEV, CVE/NVD, vendor advisories, threat intel, observed telemetry.
Outputs: exploitability context, active-threat flags, ATT&CK mappings, confidence notes.

SCS-05 · SCALE

Cyber Risk Quantification Agent

Turns technical exposure into explainable mission risk.

Inputs: asset criticality, exposure, threat, controls, business impact, recovery assumptions.
Outputs: risk score, consequence narrative, priority band, assumptions and uncertainty.

SCS-06 · QUARTERMASTER

Remediation Planner Agent

Builds the shortest defensible path from finding to fix.

Inputs: prioritized findings, architecture, maintenance windows, compensating controls.
Outputs: remediation playbook, owner, SLA, dependencies, rollback plan, ticket payload.

SCS-07 · ROUTER

Workflow Orchestration Agent

Moves approved work into delivery systems and watches aging.

Inputs: approved plans, ITSM/backlog APIs, ownership directory.
Outputs: tickets, assignments, SLA timers, escalations, status synchronization.

SCS-08 · PROVING GROUND

Validation Agent

Refuses ceremonial closure. Re-tests whether risk was actually removed.

Inputs: completed tickets, scanner/test results, configuration and control telemetry.
Outputs: validated closure, failed-remediation reopen, residual-risk record, evidence bundle.

SCS-09 · SCRIBE

Control Evidence Agent

Maintains audit-ready traceability from controls to operational proof.

Inputs: policies, NIST/CIS/PCI mappings, logs, configs, approvals, test evidence.
Outputs: evidence register, freshness score, POA&M candidates, control gaps, audit packet.

SCS-10 · WATCHTOWER

Resilience + Incident Readiness Agent

Tests whether detection, response and recovery claims have proof behind them.

Inputs: IR plans, backup logs, restore tests, detection coverage, exercises.
Outputs: readiness score, unverified-backup HIGH risk flag, exercise backlog, recovery evidence.

SCS-11 · BOARDROOM

Executive Cyber Briefing Agent

Compresses the machine room into decisions leaders can make.

Inputs: risk register, trends, MTTR, exceptions, SLA breaches, mission context.
Outputs: executive brief, decision queue, heat map, trend narrative, investment options.

SCS-12 · SENTINEL GOVERNOR

Agent Governance Agent

Polices the agents themselves: permissions, provenance, boundaries and drift.

Inputs: agent logs, tool grants, prompts/policies, actions, exceptions.
Outputs: authorization findings, autonomy violations, kill/hold recommendations, immutable audit trail.

Human authority gates

Human approval required before production firewall/IAM changes, destructive actions, risk acceptance, exception approval, public/client attestations, legal/compliance conclusions, or actions with material mission impact. Agents may recommend and prepare these actions, not silently authorize them.
