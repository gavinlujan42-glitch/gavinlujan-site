# PROTO Free-Tier Lock Policy

**Effective:** 2026-11-22

## Non-negotiable deployment rules
1. No paid AI APIs, paid inference, metered services, or credit-card-dependent providers in the PROTO experience.
2. No automatic conversion from free to paid plans; no silent billing or usage overages.
3. Keep the core guide functional as a static, client-side, curated knowledge navigation experience, with no external inference dependency.
4. No visitor chat logging, API keys, or private information in public JavaScript or static site files.
5. Any future remote model must be an explicitly approved optional enhancement with hard zero-spend controls and a reliable offline/static fallback. A vendor's free tier is not guaranteed to last forever.
6. Never claim the curated guide is a live generative AI model, a live SOC feed, or a verified real-time data source.
7. Hosting or domain fees outside the prototype's AI inference path are not covered by this policy; confirm them separately.

## Current implementation
- Static GitHub Pages-compatible HTML, CSS, and JavaScript.
- Deterministic, topic-based answers linking to existing public site pages.
- No API key, model endpoint, telemetry, or external AI billable request.
- Purple executive theme preserved.

## Future enhancement gate
Before adding retrieval or generative answers: obtain approval for provider, privacy terms, billing model, and explicit zero-cost limits. If no provable hard-zero-cost option exists, keep the browser-only guide.
