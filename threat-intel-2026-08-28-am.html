PaperCut is an active incident until patch and hunt say otherwise.

PaperCut confirms exploitation against NG/MF customers and has issued Emergency Patch Release 2. Overnight research also exposes unauthenticated router implants and a growing trust gap where AI agents treat web documentation as executable instruction.

EXECUTIVE JUDGMENT // OVERNIGHT DELTA

Restrict PaperCut now, install Release 2 and investigate before declaring closure.

Confirmed: PaperCut reports active exploitation and confirmed customer incidents affecting PaperCut NG and MF. On August 28 it released Emergency Patch Release 2 addressing CVE-2026-81578 and CVE-2026-82078 and recommends it even where the first emergency patch was installed. Assessment: every public-facing or remotely reachable PaperCut Application Server should be treated as potentially compromised until exposure, logs and endpoint telemetry are reviewed. The vendor has not publicly established that both disclosed CVEs were used in every observed incident.

0–2 HOURSRemove PaperCut web interfaces from untrusted access; allow only trusted administrative IPs. Inventory primary, site and secondary servers.
IMMEDIATELY AFTERInstall Emergency Patch Release 2 on supported v24–v26 systems; upgrade older deployments. Patch site and secondary servers, not only the primary.
INCIDENT CHECKPreserve and review PaperCut, endpoint, identity and network telemetry; isolate systems showing suspicious child processes, log deletion or unauthorized configuration changes.

02 // ROUTER SUPPLY-CHAIN EXPOSURE

White-labeled ZBT firmware carried unauthenticated implants.

SEVERITY · HIGHCONFIDENCE · HIGH ON TECHNICAL FINDINGATTRIBUTION · MEDIUM

VulnCheck documented DARKLANTERN, an internet-reachable passive command service, and SPEAKINGSTONE, an outbound-beaconing implant, in ZBT-derived router firmware sold under multiple brands. Scanning found 203 exposed DARKLANTERN instances across 22 countries; a sinkhole received 392 SPEAKINGSTONE devices, overwhelmingly in China.

Confirmed versus assessed: the firmware functionality, exposed devices and manufacturer/supply-chain lineage are supported by technical analysis. The researcher's characterization as domestic surveillance technology is an assessment, not an independently confirmed government attribution.

Action: search asset and procurement records for ZBT/WE826-derived and relabeled cellular routers; identify firmware provenance; remove public exposure; block unexpected management traffic; replace unsupported devices. Do not assume every ZBT-derived product or custom firmware contains these implants.

ATT&CK: T1195 Supply Chain Compromise; T1205 Traffic Signaling; T1090 Proxy; T1059 Command execution. VulnCheck research

03 // AGENTIC AI TRUST BOUNDARY

When agents execute documentation, content integrity becomes code integrity.

SEVERITY · EMERGING HIGHCONFIDENCE · MEDIUM–HIGH

Independent research reviewed 8,565 llms.txt files across 6,214 domains and found more than 237 referenced packages, domains or hosted artifacts that were unclaimed. Controlled packages produced callbacks from enterprise environments, and one third-party instruction path was linked to a confirmed malicious package that the named vendor subsequently addressed.

Assessment: this is a meaningful agentic supply-chain pattern, but the population measurements and enterprise callbacks come from one research team and require broader replication. llms.txt is an agent-facing convention—not a security control, evidence source or substitute for signed software provenance.

Action: prohibit agents from installing packages or executing commands solely because documentation instructs them to; use registry allowlists, namespaces, lockfiles, hashes/signatures, sandboxing and human approval; continuously validate first-party agent instructions and external destinations.

ATT&CK: T1195.002 Compromise Software Supply Chain; T1105 Ingress Tool Transfer; T1059. Original research · SANS cross-check

04 // RANSOMWARE & WATER-SECTOR VENDOR RISK

Supplier data theft can expose operational context without touching control systems.

SEVERITY · HIGHCONFIDENCE · MEDIUM–HIGH

Reuters reports that the Barracuda ransomware group claimed theft of approximately 644 GB from water-technology supplier Micro-Comm. The FBI is investigating and reportedly views the event as opportunistic rather than Iran-linked. Customer operational systems were not reported compromised, but stolen diagrams or client context could support future targeting.

Action: treat vendor breach notification as exposure discovery: rotate shared/support credentials, review remote access, identify sensitive diagrams exchanged with suppliers, restrict third-party pathways and validate offline recovery. Claims about stolen data remain subject to investigation.

Reuters, August 26 · CISA Gunra ransomware guidance

05 // PUBLIC-SECTOR & CRITICAL SERVICES

Prioritize systems that turn IT compromise into service interruption.

PaperCut is widely used in education, healthcare and local government, making exposure checks immediately relevant to public service. Separately, Boston Scientific disclosed an incident disrupting order-processing and shipping systems; cause, actor and data impact remain under investigation.

Action: identify high-dependency administrative services, predefine manual workarounds, validate third-party access and ensure incident commanders can isolate systems without waiting for perfect attribution.

07 // PHISHING SIGNAL

Polymorphism weakens static page signatures, not layered controls.

SANS ISC analyzed a phishing page that changes obfuscated JavaScript across loads and personalizes content using a target email domain. The observed implementation occasionally fails, but defenders should not rely on attacker errors.

Action: combine secure email controls, browser isolation, credential-origin binding, phishing-resistant MFA and identity anomaly detection. Capture multiple page loads during analysis rather than assuming a single specimen represents the campaign.

SANS ISC diary
